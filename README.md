# Sistema LD Imóveis

Repositório local e privado do Sistema Integrado LD Imóveis.

## Produção

https://ld-imoveis.web.app

## Componentes

- Central de Sistemas
- Painel Gerencial
- Área dos Corretores
- CRM compartilhado
- Imóveis e contratos
- Financeiro e fechamentos
- Manutenção
- Documentos e recibos
- Auditoria e Reversão
- Vitrine Pública
- Firebase Hosting, Authentication e Firestore

## Segurança

Não incluir senhas, certificados, tokens, contratos reais, planilhas de clientes ou backups com dados pessoais.

## Publicação

firebase use ld-imoveis
firebase deploy --only hosting
